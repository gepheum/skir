# Fantasy Game Skir Example

This repository demonstrates how to depend on an external Skir repository hosted on GitHub.

## Usage

To use this repository in your project, add the following entry to your `skir.yml` file:

```yaml
dependencies:
  # ...
  "@gepheum/skir-fantasy-game-example": v1.0.0
```

The key `@gepheum/skir-fantasy-game-example` identifies the GitHub repository. The value `v1.0.0` specifies the corresponding GitHub release tag.
