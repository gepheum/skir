# Documentation

Skir is a declarative language for representing data types and APIs. Define your schema once in a `.skir` file and generate idiomatic, type-safe code for TypeScript, Python, Java, C#, C++, Kotlin, Dart, Swift, Go, Rust, Zig, Gleam, MoonBit, and Elixir.
